# ☕ Maratona Java - DevDojo

Este repositório reúne meus estudos e práticas desenvolvidos ao longo do curso **Maratona Java**, ministrado pelo **DevDojo**. O objetivo é consolidar os conceitos fundamentais da linguagem Java por meio de exemplos, exercícios e pequenos projetos criados durante a jornada de aprendizado.

## 📖 Sobre este repositório

Aqui estão organizados os códigos, desafios e experimentações desenvolvidos durante os estudos. Em vez de apenas reproduzir os exemplos das aulas, procuro testar variações, explorar diferentes abordagens e registrar minha evolução no aprendizado da linguagem.

Os commits refletem o progresso contínuo dos estudos e a construção de uma base sólida em programação orientada a objetos e desenvolvimento backend com Java.

## 🎯 Objetivo

Este repositório funciona como um ambiente de prática e evolução contínua, servindo tanto como material de consulta quanto como uma forma de documentar minha trajetória de aprendizado e desenvolvimento técnico.

## 🚀 Compromisso com o aprendizado

Acredito que a melhor forma de aprender programação é colocando a mão no código. Por isso, este repositório está em constante atualização, acompanhando minha evolução e o aprofundamento nos conceitos estudados ao longo do curso.
